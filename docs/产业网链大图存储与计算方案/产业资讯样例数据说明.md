# 产业资讯样例数据说明（基于V2本体模型）

> 目标：以“产业资讯”为例，演示各类核心表存储的样例数据与含义。

## 1. 业务场景

**资讯标题**：宁德时代发布新一代磷酸铁锂电池，成本降低15%

**发布时间**：2024-10-12

**来源**：工信部官网（示例）

**涉及实体**：
- 企业：宁德时代（IndustryOrganization）
- 产品：磷酸铁锂电池（IndustrialProduct）
- 产业节点：动力电池产业链（IndustrialChain）

## 7. 说明

- 标识要素统一维护在 `identifier_elements`，实例层通过 `entity_identifiers` 复用与关联。
- Statement 层存储关系与属性值，Context 层存储来源、置信度与证据，实现可追溯性。
- 以上样例用于说明存储结构，不代表真实生产数据。
