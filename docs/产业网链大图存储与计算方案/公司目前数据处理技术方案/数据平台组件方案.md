# 数据平台组件方案

1、大数据组件运维平台：DataSophon

国产自研开源大数据管理平台，快速实现部署、管理、监控以及自动化运维基础组件和节点，支持Hadoop、Kafka、Spark、Flink、ElasticSearch、Doris、DolphinScheduler等大数据组件，快速构建稳定、高效的大数据集群服务，目前内部部署HDFS、Yarn、Spark、DolphinScheduler、ZooKeeper等组件，Hdfs文件存储系统，Yarn进行资源调度，主要是Spark采用Yarn进行数据处理任务调度。

2、数据存储：

非结构化数据：Minio集群，主要存储非结构化文件，包含专利PDF、研报pdf、企业log图片等文件

结构化数据：数据采集统一存储MongoDB，外部数据接入采用MySQL、ElasticSearch等数据库，内部数仓ODS、DW存储在Doris，国产开源高性能实时分析型数据库，支持报表分析、即席查询、统一数仓构建、数据湖联邦查询加速等使用场景，ADS应用层数据存储在ElasticSearch，支持快速检索查询。

3、数据处理：Spark引擎

采用Spark处理引擎对数据进行统一的处理，Spark支持大规模数据，支持亿级别数据处理更新，提供全面、统一的平台用户管理各种数据源的数据处理，包括SQL查询、流数据、机器学习等

4、任务调度：Dolphinscheduler

Dolphinscheduler分布式调度任务平台，支持Python、Mysql、Spark、Flink等任务执行，解决数据处理流程中复杂的依赖关系，使调度系统在处理流程中达到开箱即用功能

5、数据资源管理及数据应用

5.1、采用数睿平台对数据对应统一管理，支持Mysql、MongoDB、Doris、ElasticSearch、达梦等数据库的连接及数据管理

5.2、支持数据大屏、数据报表等分析功能

5.3、支持接入的数据进行数据服务等功能

5.4、数据安全及用户权限控制
