# 动量热度系统说明

## 📊 系统概述

动量热度系统是智链机器人的核心分析引擎，通过计算实体在时间窗口内的引用频率和变化趋势，量化产业链中的"热点实体"。系统借鉴 **Recorded Future** 的时间序列分析方法，为每个实体生成0-1归一化的动量值。

---

## 🎯 核心功能

### 1. 动量计算引擎

**计算公式**：

```python
动量值 = 归一化(Σ 时间衰减权重 × 引用次数)
```

**参数配置**：
- **时间窗口**：默认30天
- **衰减系数**：0.95（越新的数据权重越高）
- **更新频率**：每小时自动计算

**示例**：

```python
# "谐波减速器" 实体的动量计算
最近7天引用: 50次 × 权重1.0 = 50
7-14天引用: 30次 × 权重0.95 = 28.5
14-30天引用: 20次 × 权重0.90 = 18
总动量 = 归一化(96.5) = 0.7776 (77.76%)
```

### 2. 可视化效果

#### 节点颜色渐变

- **0-25%（蓝色）**：低热度，冷门实体
- **25-50%（绿色）**：中低热度，稳定实体
- **50-75%（橙色）**：中高热度，上升实体
- **75-100%（红色）**：高热度，热点实体

#### 动态效果

1. **光环脉动**（动量>60%）
   - 红色虚线光环
   - 1秒脉动周期
   - 透明度0.3-0.8
2. **节点缩放**（动量40-60%）
   - 节点大小±20%波动
   - 1秒周期
3. **粒子流动**（动量>30%的连接）
   - 小圆圈沿连接线移动
   - 从低动量→高动量节点
   - 速度：800-1500ms/次

#### 连接线渐变

- 根据两端节点动量生成渐变色
- SVG linearGradient实现
- 可视化信息流动方向

### 3. 时间轴分析

**历史趋势图**：
- X轴：时间（最近30天）
- Y轴：动量值（0-100%）
- 折线图展示动量变化
- 自动标注峰值点

**趋势判断**：

```python
if 动量增长率 > 20%:
    趋势 = "快速上升"
elif 动量增长率 > 5%:
    趋势 = "稳步增长"
elif 动量增长率 < -20%:
    趋势 = "快速下降"
else:
    趋势 = "稳定"
```

## 🔍 情报溯源机制

### 数据来源追踪

每个实体的动量值都可追溯到具体的文档实例：

```json
{
  "entity_id": "CANONICAL_PRODUCT_谐波减速器",
  "current_momentum": 0.7776,
  "reference_count": 100,
  "sources": [
    {
      "title": "特斯拉人形机器人Optimus二代发布",
      "source": "百度资讯",
      "url": "https://...",
      "created_at": "2025-12-20T08:00:00Z"
    },
    // ... 更多来源
  ]
}
```

### 引用统计

- **总引用数**：实体在所有文档中被提及的次数
- **来源分布**：按数据源（百度/OFweek/36Kr）统计
- **时间分布**：按日期统计引用趋势

### 来源可信度评分

每个数据源分配不同类别的可信度：

```python
sources = {
  "百度资讯": {"technology": 0.7, "finance": 0.6, "general": 0.8},
  "OFweek机器人": {"technology": 0.9, "finance": 0.5, "general": 0.7},
  "36氪": {"finance": 0.9, "technology": 0.8, "general": 0.8}
}
```

实体的平均可信度 = Σ(文档可信度 × 引用权重)

## 📈 使用场景

### 场景1：发现热点产品

**需求**：找到最近最火的机器人零部件

**操作**：
1. 访问"动态分析"页面
2. 按"动量值"降序排列
3. 查看TOP10实体
4. 点击"情报溯源"查看具体新闻

**结果示例**：

```
1. 谐波减速器 - 77.76% ↑ (100次引用)
2. 伺服电机 - 65.34% ↑ (85次引用)
3. 工业机器人 - 58.21% → (70次引用)
```

### 场景2：监测企业热度变化

**需求**：跟踪特斯拉人形机器人项目的舆论热度

**操作**：
1. 搜索"特斯拉"或"Optimus"
2. 查看时间轴趋势图
3. 分析动量峰值时间点
4. 溯源到具体事件（如产品发布、融资新闻）

**洞察示例**：

```
12月15日动量峰值 (85%) - 原因：
- 特斯拉发布Optimus二代视频
- 36氪、OFweek等15家媒体报道
- 微博热搜#特斯拉机器人#话题
```

### 场景3：识别异常波动

**需求**：自动发现动量剧烈变化的实体

**操作**：
1. 系统每小时自动计算
2. 检测动量变化率 > 阈值（如50%）
3. 发送Webhook通知
4. 管理员审查异常原因

**示例**：

```
🚨 异常检测
实体：某创业公司
动量变化：从12% → 78% (7天内)
原因：获得腾讯B轮融资，多家媒体集中报道
```

## 🔧 配置优化

### 调整动量计算参数

编辑 `backend/config/settings.py`:

```python
# 时间窗口（天）
MOMENTUM_WINDOW_DAYS = 30

# 衰减系数（0-1，越小则旧数据权重越低）

# 更新频率（Celery任务，cron表达式）
MOMENTUM_UPDATE_SCHEDULE = "0 * * * *"  # 每小时
```

## 🎓 最佳实践

### 1. 数据质量保证

- **定期更新数据源**：每周审查RSS订阅源，删除失效源
- **过滤垃圾数据**：设置关键词黑名单，排除广告文章
- **人工校验**：对动量>80%的实体进行人工复核

### 2. 性能优化

- **批量计算**：每小时批量更新，避免实时查询
- **缓存策略**：动量值缓存30分钟
- **索引优化**：MongoDB的`entity_references.entity_id`字段建立索引

### 3. 业务应用

- **投资决策**：关注动量快速上升的创业公司
- **竞品分析**：对比同类产品的动量趋势
- **舆情监测**：设置动量波动告警，及时响应负面新闻

## 📞 常见问题

**Q: 为什么某个实体动量显示0？**
A: 可能原因：
1. 最近30天内无新闻引用
2. 实体刚创建，尚未计算
3. 等待定时任务更新（每小时一次）

**Q: 如何手动触发动量计算？**
A:

```bash
docker exec zhilian-backend python -c "
from app.analytics.momentum import MomentumEngine
engine = MomentumEngine()
engine.update_all_entities()
"
```

**Q: 动量值突然下降怎么办？**
A: 这是正常现象，说明：
1. 近期新闻热度下降
2. 其他实体热度上升（相对排名变化）
3. 时间衰减导致旧数据权重降低
