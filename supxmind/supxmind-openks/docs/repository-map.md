# OpenKS Repository Map

## 主结构

- `openks/common`：公共 schema、基类、注册表、工具。
- `openks/kg`：事实类、认知类、决策类知识库。
- `openks/cross`：跨 KG 编排与同步。
- `openks/entry`：启动、CLI、API 入口。
- `tests`：基础回归测试。

## 当前目标

- 把平台后续新增的 `news / report / policy / patent / industry_chain` 等知识库优先落到此仓。
- 通过统一注册表与总配置约束目录结构，方便多人并行实现。
- 给前端“知识计算”栏目提供明确的模块地图与职责边界。
