# 数据平台技术方案0329

## O、数据平台需求与目标

产业大数据具有数据规模大、多源异构、数据处理过程复杂冗长等特点。因此需要构建产业大数据平台以满足日益增长和复杂的需求：

*   支持海量数据规模处理：百亿级数据规模
    
*   支持多源异构数据源接入：文件、数据API、数据库等来源以及结构化、半结构化、非结构化数据
    
*   支持复杂的数据治理过程：包括数据清洗、关联计算、知识抽取等数据治理过程
    
*   支持高效的数据运营工作：支持人工在平台上对数据质量进行运营
    
*   支持高效复杂的数据关联分析和取数：支持表深度关联分析以及快速取数
    
*   支持友好的数据可视化：支持无代码的数据展示和分析
    
*   国产信创：国产信创生态
    
*   一键部署：采用容器云等方式实现快速一键部署

## 三、数据生产管理

### 3.1 数据接入

多源数据接入组件是量知数据平台一个重要的组件，用于各个不同数据源的公开数据采集接入。针对互联网上各种数据，格式繁多根据不同的数据源特点和业务场景，可以将同一场景下同一类数据的采集模式抽象化形成组件提供给上层应用。这样可以避免对相近内容的采集代码重复开发，提高数据采集效率。同时它不仅限于数据采集，还能对各种形式数据源例如数据库数据、文件数据、API接口数据等进行数据导入，是整个天篷大数据平台的数据生产入口和发起者。

![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eLbnj88NoAW8OaNY/img/79f76d2e-d81c-45fd-a3bf-b47590aa0944.png)![image.png](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/eLbnj88NoAW8OaNY/img/95179247-4e28-4bdb-8814-a4609fa991c0.png)

### 3.2 多模态数据存储

多模态数据存储引擎是一款数据接入到存储的管理套件，主旨在于提供一类将游离在外部的数据稳定、高效的接入并存储到指定内部存储数据空间的工具。天蓬大数据平台采用MongoDB、Doris、ElasticSearch、OSS等实现多模态数据存储，存储的数据将作为原始数据供后续的数据生产环节使用。可以存储结构化（表格或图形）、半结构化（CSV、JSON、日志）、非结构化（pdf文档、word文档、照片等）。

### 3.2 数据开发治理

#### 3.2.1 数据标准体系

在数仓建设中，数据标准是至关重要的环节，它涉及数据的收集、处理、存储、分析和应用等多个方面。

1、数据建模标准：

*   选择合适的建模方法，如维度建模或规范化建模，根据业务需求和数据特征确定最佳的数据模型。
    
*   规范数据模型的设计和管理，确保数据的一致性和可维护性。采用统一的数据建模方法和建模工具，减少数据冗余和不一致性。
    

2、数据质量标准：

*   制定数据质量管理流程和数据质量指标，包括数据的准确性、完整性、一致性和及时性等。
    
*   设定数据清洗和验证的规则，以确保数据的质量符合标准。在数据抽取、转换和加载过程中，应用这些规则对数据进行质量检测和清洗。
    

3、数据集成标准：

*   确定数据集成的方法和技术，如ETL（提取、转换、加载）工具或数据仓库中间件等。
    
*   制定数据交换和共享的规则，确保不同系统之间的数据能够高效、安全地集成和交换。
    

4、数据安全标准：

*   建立完善的数据安全管理体系和安全策略，包括数据加密、访问控制、审计和备份等。
    
*   确保数据的机密性、完整性和可用性，防止数据泄露、篡改或丢失。

#### 3.2.3 元数据管理

元数据是描述数据的数据，包括数据的属性、关系、质量、条件以及数据管理和应用的信息。元数据通常用于数据管理、数据治理和数据分析等场景，帮助用户更好地理解和管理数据。元数据列表主要包含数据资产预览、数据结构设计、数据关联关系、数据血缘关系、数据权限管理、数据生命周期管理。

#### 3.2.6 数据安全

天蓬大数据平台保证系统数据安全，支持数据的安全规则配置，包括数据的加密算法和密钥等。对密钥和安全规则进行管理，包括创建、修改和删除。其中，密钥仅创建者可使用，且一旦创建不可删除，数据安全仅规则的创建者才可管理和使用。

天蓬大数据平台建立应用系统的访问用户的身份授权的管理机制，以降低由于对应用及数据的未经授权的访问带来的风险。在应用权限管理的过程中，会将用户根据角色进行分类，并赋予不同角色不同的应用菜单权限。
